## Pane layout

lazyaz uses a **miller-columns** layout — parent, focused, and child panes
arranged left to right. As you drill into resources, the focused pane shifts
right and the previous pane becomes the parent column on the left.

The **Notifications history** (`N`) overlay keeps the last 1 000 events.
Transient toasts auto-dismiss after ~1.5 s (or 5 s for errors). Errors from
background fetches land here too — including fetches in tabs you're not
currently looking at — so a failed refresh is never silently lost. The
**Activity overlay** (`F`) shows in-flight cache fetches across all tabs
and lets you cancel them mid-flight — note that some long-running
operations (Service Bus requeue/move) are not yet routed through it.

## Filtering

Every filter in the app — pane filters (`/`), overlay pickers, the command
palette, the file browser — uses fzf's matching algorithm and understands
fzf's extended-search syntax. Matching is case-insensitive.

| Pattern | Matches |
|---|---|
| `logs` | fuzzy match |
| `'logs` | exact substring |
| `^data` | prefix |
| `.json$` | suffix |
| `^app$` | exact equal |
| `!tmp` | does not contain `tmp` (also `!^data`, `!.tmp$`) |
| `^data .json$` | AND — all space-separated terms must match |
| `'parquet \| 'avro` | OR — pipe joins alternatives |

Use `\ ` (backslash-space) to match a literal space. Note: the Blob tab's
*server prefix search* sends a literal prefix to the Azure API and does not
use this syntax.

Filters match the visible row text. One exception: the Service Bus
*messages* pane also matches the message body preview, so you can find a
message by its content.

## Action menu

Press `a` to open a context-aware action menu for the current pane. The menu
shows only actions relevant to your current selection — download, yank, sort,
requeue, and more depending on the resource type. Type to filter, `Enter` to
execute.

## Command palette

Press `Ctrl+P` to open the command palette. It lists every available
command grouped by section — new tabs (Blob / Service Bus / Key Vault /
Dashboard / Azurite preset / Blob-by-connection-string), open tabs (`Go to
Tab N`), tab management (close / next / previous), the **Azure Login /
Switch Tenant** flow, theme picker, notifications history, activity
overlay, help, and quit. Type to fuzzy-filter, `Enter` to execute.

Note: switching subscription is not in the palette — it's the top-level
shortcut `S` (or `Ctrl+S` in standard).

## Jump list

lazyaz keeps a vim-style jump list that tracks where you've been across
tabs, following vim's rules: a jump is a scope change — drilling into a
different container, folder, vault, kind, namespace, or queue, switching
subscription, or jumping between tabs. Local motion (cursor moves, pane
focus changes, scrolling) is never recorded. The position you were at when
you jumped is what gets recorded, down to the folder and the selected row,
so `Ctrl+O` puts the cursor back exactly where you left.

| Key | Action |
|---|---|
| `Ctrl+O` | Jump back to the previous position |
| `Ctrl+I` / `Ctrl+N` / `Ctrl+]` | Jump forward |

Jumps cross tab boundaries — pressing `Ctrl+O` can return you to a different
tab you had open (including the dashboard, which restores the focused
widget). Making a new jump while walked back abandons the forward history,
exactly like vim. The list holds up to 100 entries and is deduplicated so
rapid back-and-forth doesn't bloat it.

Some terminal + multiplexer combinations can't distinguish `Ctrl+I` from `Tab`,
which is why `Ctrl+N` and `Ctrl+]` are also bound to jump forward.
